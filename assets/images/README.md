# Assets - Imagens

## Imagem de Fundo para Login/Registro

Adicione a imagem do sistema respiratório aqui com o nome:
- `respiratory-background.png` (recomendado) ou
- `respiratory-background.jpg`

A imagem será usada como fundo nas páginas de login e registro.

### Como adicionar a imagem:

1. Salve a imagem do sistema respiratório neste diretório (`assets/images/`)
2. Nomeie o arquivo como `respiratory-background.png`
3. Se a imagem não existir, o app usará um gradiente azul como fallback

### Características da imagem:

- Ilustração médica do sistema respiratório (pulmões, traqueia, brônquios)
- Estilo translúcido/glow com fundo azul escuro
- Cores: azuis para estrutura óssea, rosa/vermelho para órgãos respiratórios
- Formato recomendado: PNG com transparência ou JPG de alta qualidade
